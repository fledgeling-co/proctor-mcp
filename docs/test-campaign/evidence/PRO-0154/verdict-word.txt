== A FAULT IN THIS SCANNER, FOUND WHILE ARMING IT ==
The first attempt at the arm did not fire, and the reason was not the verdict
logic. FIGURE carried a lookahead (?!\s*[a-z]) added to stop '6,182 spec
citations' being read as 6,182 specs. It rejects ANY figure followed by an
ordinary lowercase word — so 'Test run with 2173 tests in 275 suites' was never
matched at all, because 'tests' is followed by ' in'.

Every figure written in a sentence went unscanned. Only figures sitting in table
cells, followed by a pipe or a separator, were ever read. The page this gate
exists to catch was not rejected by a rule; it was invisible.

  checkable figures before the fix:  193
  after:                             326

Replaced with a named qualifier list — citations, symbols, names, ids, files,
paths, references, directories, entries, lines — so the subject-changing word is
enumerated rather than approximated by 'any word at all'.

== THE VERDICT VOCABULARY ==
bad 13 · good 125 · mixed 13 · none 175, over 326 figures.
A figure with no verdict word beside it is the common case and is not a finding.
A line carrying BOTH a positive and a negative word is 'mixed' and is not
resolved: deciding which governs is reading prose, and this file does not.
A negative verdict is a finding only where the document's own heading claims the
work is finished — otherwise it is an ordinary record of something that failed.
