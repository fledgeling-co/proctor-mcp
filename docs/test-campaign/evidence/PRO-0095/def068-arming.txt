What no case here proves: that the file was never wider for an instant.
The window is unobservable from a test in the same process. It is closed by
construction instead — the temporary is created by Darwin.open with mode
0o600 and O_EXCL, so no descriptor to a wider file ever exists, and the
replace is a rename. O_EXCL is what makes the mode argument bind: open
applies it only when it creates the file, so O_TRUNC over a stale 0644
temporary would have reused that mode.
