Proctor

Two permissions, asked once

macOS holds these, not Proctor. Granting them here asks the system directly.

Accessibility
Read the tree, and write to it. Without it, every tree comes back empty.
Screen Recording
Window pixels, and the frame status that says whether they are fresh.

Screen Recording needs Proctor to restart before it takes effect. Proctor will say so when it lands.

Continue is disabled and visible rather than absent — a control that disappears makes the layout jump and teaches the user the step does not exist. Only one Grant is prominent at a time: the one to press next.
