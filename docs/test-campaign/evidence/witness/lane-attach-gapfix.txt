## instrument change made in this session

only events carrying the probe's own mark, which the TAGGED arm does not carry — a tagged
post stamps the Proctor tag instead — so that field is pinned at zero on the tagged arm
whatever the block does. Read off it, the two-way sabotage would have reported "swallowed"
for ten events that sailed straight through. The new field counts by source pid, which
both arms carry, so the same number can come back non-zero on one arm and zero on the other.
