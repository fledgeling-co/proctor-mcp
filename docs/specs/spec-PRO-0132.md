## Context & Purpose
Provide an automated helper to evaluate warrant charter prerequisites, format promotion proposals, and maintain the signed charter advancement ledger.

## Acceptance Criteria
1. Helper evaluates prerequisite check statuses across all defect classes.
2. Qualifying classes generate structured promotion proposals with complete figure counts.
3. Actionable diagnostic messages identify missing criteria for blocked classes.
4. Ratification records format signature blocks according to charter specifications.
