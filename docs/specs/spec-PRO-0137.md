## Context & Purpose
Provide a standalone dashboard exporter to generate portable visual summaries of warrant charter assurance levels, promotion blockers, and ratchet trends across defect classes.

## Acceptance Criteria
1. Dashboard exporter reads charter configurations, health records, and promotion proposals.
2. Interactive visual cards display current tier status and figure sourcing percentages for each class.
3. Promotion blockers are highlighted with specific corrective actions for each blocked class.
4. Standalone report generates as a single portable file with zero external network dependencies.
