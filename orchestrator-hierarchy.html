The split this wave assumes, and it is not negotiable in either direction

Cua owns actuation. Clicks, typing, keys, scrolling, drags, menus, window targeting. Proctor calls it rather than reimplementing it.

Proctor owns observation, and this is the half a counter-review forced. Cua returns screenshots with no frame-status metadata, while Apple defines six SCFrameStatus values and makes checking them a precondition of trusting a frame. A verification layer needs at least one channel it can trust, so Proctor keeps its own capture path.

Proctor owns the verdict and the supervision: assertions, the accessibility audit, fidelity, determinism, the tri-observer check; and the HUD, the character, the queue, Stop, the policy gate and the signed trail.

Measurements the next fleet must not re-derive

An overlay panel sized to the union of the displays is a ~26-megapixel backing store that the window server accepts and reports onscreen=1, alpha=1 while never presenting. One panel per screen, every time.

A structured withTaskGroup race cannot bound a call parked in a non-cancellable continuation: the timer fires, the race resolves, and the group never returns because it awaits its children.

swift test --filter matches the Swift function name, not the @Test display string. A filter on the display string runs zero tests and reports green.

hud.onScreen reports whether the panel was built, not whether it is presented. It is a belief; the window list is the instrument.
