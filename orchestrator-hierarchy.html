Four things the next fleet must not re-litigate

An overlay panel sized to the union of the displays is a ~26-megapixel backing store that the window server accepts and reports onscreen=1, alpha=1 while never presenting. One panel per screen, every time.

hud.onScreen reports whether the panel was built, not whether it is presented. It is a belief. The window list is the instrument that works.

Place a panel from visibleFrame, never frame: an inset measured from the physical corner puts the panel's lower third behind the Dock.

swift test --filter matches the Swift function name, not the @Test display string. A filter on the display string runs zero tests and reports green — read the with N tests count back before believing it.

Two decisions that were the reader's, and were made

The sealed audit trail has no recovery copy: a lost keychain key means a permanently unreadable history, chosen deliberately over an export path that would weaken the guarantee sealing was for.

browser-use is off unless the operator turns it on, because installing a CLI is consent to have a file, not consent for an Accessibility-holding process to name that file to a model with a shell.
